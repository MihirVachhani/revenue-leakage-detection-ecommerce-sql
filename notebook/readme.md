# SQL Database Setup Using Python

This folder contains Jupyter Notebook code used to connect Python with MySQL Workbench and upload CSV files into the SQL database.

### What I Did
- Connected Python to MySQL using a SQL connection.
- Loaded CSV files using Python and Pandas.
- Uploaded the CSV data into MySQL tables.
- Set up the database for further SQL queries and analysis.

### Tools Used
- Python
- Jupyter Notebook
- Pandas
- MySQL Workbench

### Files
- `*.ipynb` – Notebook containing the database connection and CSV upload code.
