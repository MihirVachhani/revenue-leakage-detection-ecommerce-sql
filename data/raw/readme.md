# Data

This project uses the Olist Brazilian E-Commerce Dataset.

The original dataset can be downloaded from Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Raw files are not included in this repository due to size considerations.

Files used:

- customers
- orders
- order_items
- payments
- reviews
- products
- sellers
- geolocation
- product_category_translation
