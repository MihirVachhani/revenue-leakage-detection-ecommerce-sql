# Exploratory Business Analysis
## Revenue Leakage Detection in an E-Commerce Marketplace

---

# Objective

Before investigating revenue leakage, it is essential to understand how the marketplace operates.

This exploratory analysis establishes baseline knowledge of:

- Marketplace Scale
- Revenue Performance
- Seller Ecosystem
- Customer Satisfaction
- Delivery Performance

The insights generated in this phase will provide context for the KPI framework and support the investigation of revenue leakage indicators in subsequent phases.
